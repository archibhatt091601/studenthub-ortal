# Practical 2 – StudentHub Portal: HTML Structure

## Overview
This practical builds on the sitemap and wireframe from Practical 1 by implementing the **static HTML structure** of the StudentHub Portal website. No CSS styling is applied in this stage — the focus is purely on semantic HTML markup and page structure.

## Contents
| File | Description |
|------|--------------|
| `home.html` | Landing page with welcome/hero section |
| `about.html` | Information about the platform (introduction, mission, features) |
| `register.html` | Student registration form |
| `login.html` | Login form with email and password fields |
| `dashboard.html` | Student dashboard with menu and quick actions |
| `events.html` | Upcoming events listing |
| `profile.html` | Student profile page with personal details |
| `contact.html` | Contact form |
| `faq.html` | Frequently asked questions |
| `feedback.html` | Feedback submission form |

## Notes
- All pages link to a `style.css` file in the `<head>`, but the stylesheet is **not included** in this practical — pages will render unstyled (plain HTML).
- Navigation is consistent across all pages via a shared `<nav>` menu linking to every page.
- This practical corresponds directly to the sitemap structure defined in Practical 1.

## How to Run
1. Download/copy all `.html` files into the same folder.
2. Open `home.html` in any web browser.
3. Use the navigation bar to move between pages.

## Purpose
Demonstrates the ability to translate a sitemap/wireframe into working semantic HTML pages with proper navigation, forms, and content structure — prior to applying visual styling.
