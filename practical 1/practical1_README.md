# Practical 1 – StudentHub Portal: Sitemap & Wireframe

## Overview
This practical covers the planning and design phase of the **StudentHub Portal** website — a student engagement platform. It includes the site's information architecture (sitemap) and a low-fidelity wireframe of the layout.

## Contents
| File | Description |
|------|--------------|
| `sitemap` | Text-based sitemap outlining the site's page hierarchy and structure |
| `wireframe.drawio.png` | Wireframe image showing the visual layout of the pages, created using draw.io |

## Site Structure
The sitemap defines the following pages and their sub-elements:

- **Home**
- **About** – Introduction, Mission, Features
- **Register** – Student Registration Form, Register Button
- **Login** – Email Address, Password, Login Button
- **Dashboard** – Welcome Student, Menu (View Profile, Events, Notifications, Logout), Quick Actions
- **Event** – Upcoming Event 1, 2, 3
- **Profile** – Student Information, Profile Photo, Personal Details, Edit Profile
- **Contact** – Name, Email, Message, Submit
- **FAQ** – Registration Queries, Login Issues, Event Information, General Questions

## Purpose
This practical demonstrates the ability to plan a website's structure and navigation flow before development, establishing the foundation used in Practical 2 and Practical 3.

## How to View
- Open `sitemap` in any text editor to view the hierarchy.
- Open `wireframe.drawio.png` in any image viewer, or import it into [draw.io](https://app.diagrams.net/) to edit.
