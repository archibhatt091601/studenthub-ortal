# Practical 3 – StudentHub Portal: Styled Website (HTML + CSS)

## Overview
This practical extends Practical 2 by adding a shared **CSS stylesheet** (`style.css`) to style all pages of the StudentHub Portal website, completing the visual design of the site.

## Contents
| File | Description |
|------|--------------|
| `home.html` | Landing page with welcome/hero section |
| `about.html` | Information about the platform |
| `register.html` | Student registration form |
| `login.html` | Login form |
| `dashboard.html` | Student dashboard |
| `events.html` | Upcoming events listing |
| `profile.html` | Student profile page |
| `contact.html` | Contact form |
| `faq.html` | Frequently asked questions |
| `feedback.html` | Feedback submission form |
| `style.css` | Shared stylesheet applied across all pages |

## Styling Highlights (`style.css`)
- Global reset for margin and text color.
- Blue-themed `header` and `h1` banner with white text.
- Light (`aliceblue`) background used for hero/section highlights.
- Individual class names (`m`, `m1`–`m9`) applied to navigation links for per-link styling/highlighting.
- Consistent look and feel maintained across all pages via the single shared stylesheet.

## How to Run
1. Keep all `.html` files and `style.css` together in the same folder (do not separate them).
2. Open `home.html` in any web browser.
3. Navigate through the site using the styled navigation bar.

## Purpose
Demonstrates the ability to apply CSS to a multi-page HTML site to achieve a consistent, styled user interface — completing the full workflow from sitemap (Practical 1) → structure (Practical 2) → styled site (Practical 3).
